# Storage / Outbox 阶段进度（2026-09-06）

## 已实现

- Store 打开、关闭、SQLite 配置、v2 schema 创建及 v1→v2 迁移。
- Measurement 和 pending Outbox 在同一事务内保存。
- 读取最早 pending，并管理输出字符串所有权。
- 标记 sent、记录投递失败、查询统计数量。
- edgevision_storage 静态库及可选构建开关，默认关闭。
- Gateway 服务模式下的 Store 和 Publisher 生命周期。
- 模拟数据周期采集，先保存再投递。
- MQTT 直接发布已保存的 topic/JSON，等待对应 QoS 1 PUBACK。
- 发布成功后标记 sent；失败后记录原因并保留 pending。
- 每轮最多投递 10 条，空队列或发布失败时结束本轮投递。
- 启动时输出数据库统计。
- 支持独立命令行选项 --db <database_path>。

## 当前行为

- 仅开启 Storage：周期采集并保存。
- 同时开启 Storage 和 MQTT：采集保存后尝试投递。
- 模拟数据源每次进程启动重新初始化。
- 每轮工作结束后等待约 1 秒，采集间隔包含数据库及发布耗时。
- 正常退出时依次销毁 Publisher、关闭 Store、清理日志。
- 两个 smoke 模式沿用原流程。
